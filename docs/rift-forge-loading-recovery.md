# Rift Forge 0.10.1：慢速素材下載自動恢復

0.10.0 正式站驗收時，Chromium 與 WebKit 的冷載入均超過既有 12 秒期限。資源皆為 HTTP 200，完整 SHA-256 也與部署提交一致，但原載入器把 timeout 視為永久完成，忽略稍後的成功事件。獨立 Chromium 觀察中，15 張圖集於約 53.23 秒自然完成下載；按一次既有重試按鈕，約 0.25 秒即可恢復。這是可重現的可用性問題，不能只靠部署成功判定驗收通過。

本修正保留 12 秒提示期限與內容雜湊版本網址：

- 等待過久顯示「素材下載較慢，完成後會自動恢復」，保留原請求；正確尺寸的圖集稍後完成，便重新計算已就緒數量。
- 所有圖集真正成功後才開放開始、繼續與選角；`onerror`、錯誤尺寸或建立繪圖快取失敗仍封鎖並顯示重試。
- 將載入進度與重試控制放在開始按鈕下方，手機不必捲到長首頁底部找恢復入口。
- 重試保留同版本、已成功驗證的素材，只重取慢速或失敗項目。重複點擊共用正在正常進行的批次。
- 每一批次有獨立識別；替換批次時清理舊 timer／回呼，舊成功或失敗不能改寫目前狀態。Promise 的逾時結果不會把晚到成功重新鎖定。
- 成功通知只刷新仍開啟的首頁，不會將圖鑑、基地或戰鬥強制切回首頁。

本修正不改戰鬥數值、角色、章節或任何存檔 key。兩個瀏覽器以可控的真實圖片請求與虛擬時鐘覆蓋期限內完成、逾時後自動恢復、永久失敗、重試及重複點擊。既有圖集、存檔與舊快取更新測試一併保留。實際執行與發布結果以 PR／Actions 及本次驗證紀錄為準，不將預定測試當作已通過。
