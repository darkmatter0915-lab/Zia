# 彈核熔爐 0.9.0：第二章「霜骸王庭」

第一章通關後，結算畫面可承接本局等級、彈核、刻印、生命上限與事件永久增益，繼續第二章。生命與脈衝補滿，第二章戰利品重新計算，兩章各結算一次。已保存通關紀錄的舊玩家可從標題畫面直接挑戰，無須重破第一章；直接出征為 Lv.10、二階火／冰／電彈核，繼承基地強化。

## 關卡與戰鬥

六波、每波 28 秒；第 2、5、6 波進入三次不重複的既有隨機事件。第 3 波結束迎戰凜獄斬刑者，勝利後補給並進入第 4 波；第 6 波結束迎戰霜骸女王。

| 敵人 | 新行為 | 應對方式 |
| --- | --- | --- |
| 晶盾衛士 | 三層晶盾減少直接命中傷害 | 逐次擊碎或用反彈彈核一次破盾 |
| 裂冰獵犬 | 停下蓄力、鎖定位置後加速撲擊 | 蓄力期間移開，不留在預告落點 |
| 寒咒巫靈 | 雙冰錐與延遲冰封區 | 離開預警；閃避解除寒霜緩速 |
| 凜獄斬刑者 | 雙線冰斬與扇形冰錐，半血加快 | 在兩道冰斬間移動，保留閃避 |
| 霜骸女王 | 四區中的三區暴風雪、冰錐、召喚獵犬，半血強化 | 找到每次留下的安全區，兼顧召喚怪 |

寒霜命中後移速降低 30%，持續 1.2 秒；有無敵時間時不施加緩速。女王召喚數量受控，預警與安全區在精簡特效中仍保留。

## 已套用美術

五套新角色圖集各六個動作，包含待機、兩步移動、蓄力、攻擊與受擊；768×512 WebP、3×2 格、每格 256、腳底基準 (128,240)。冰封玄武岩與銀色雪花陣場景為 1152×768 WebP。新增素材合計約 916 KiB。

原圖由 image_gen 製作；獵犬、巫靈、斬刑者、女王另經 image_gen 修正間距，避免相鄰影格溢出。最終只進行裁切、縮放與 WebP 圖集封裝，沒有手繪替換生成內容。完整提示詞、模式與素材路徑在 [rift-forge-v09-art-prompts.json](rift-forge-v09-art-prompts.json)。

章節資訊納入存檔；沒有章節欄位的舊存檔維持第一章。戰鬥素材未完整載入時可重試；裝飾性冰封地板載入失敗時改用原生備援地板，仍可進入遊戲。所有腳本、樣式、圖集及兩章地板均使用內容雜湊網址。
