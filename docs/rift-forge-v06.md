# Rift Forge 0.6.0 — 攻擊特效、三場 Boss 與事件

## 玩家可見的更新

- 九種球核重做尾流、命中碎片、電弧、吸血回流及進化爆發。尾流跟隨真實反彈路徑；完整特效與精簡特效都保留危險區輪廓、倒數與文字提示。
- 保留八波敵襲，第三波後新增「熔獄巨顎」、第六波後新增「裂星司祭」，最終仍為「熔鐘守衛」。三者有各自的外觀、招式、血量與半血狂暴階段。
- 巨顎使用扇形火彈與熔裂重擊；司祭使用瞄準星彈、雙區星隕與召喚；守衛使用密集彈幕及落點重擊。地面攻擊先預告 1.3–1.45 秒，才判定傷害。
- 中途 Boss 戰停止波次推進；擊破後回復 18 生命、充能 25%、進入原有波次補給。只有最終守衛死亡會結算勝利。
- 進入第 3、6、8 波前各觸發一次事件。從月泉、行囊、契壇、共鳴、鑄匠五種事件隨機抽取，單局不重複。每件事有兩個有實際收益／代價的選項，並可選擇離開。
- 事件中暫停戰鬥；事件順序、目前選項與已選結果都寫入存檔。舊版存檔保留進度，已錯過的事件不回放。

## 美術資產

使用內建 image_gen 生成兩組原創透明 Boss 圖集，再以同一工具調整姿勢間距。現有封裝腳本只做裁切、縮放、拼接與 WebP 壓縮。

| Boss | 遊戲素材 | 大小 | 姿勢 |
| --- | --- | --- | --- |
| 熔獄巨顎 | `public/rift-forge/assets/sprites/maw.webp` | 116,752 bytes | 待機、兩個移動姿勢、蓄力、攻擊、受擊 |
| 裂星司祭 | `public/rift-forge/assets/sprites/oracle.webp` | 167,232 bytes | 待機、兩個漂浮姿勢、蓄力、施法、受擊 |

每組 768×512，3×2 格，每格 256×256；使用六個關鍵姿勢，非骨骼動畫。完整原始提示及最後一次修改提示見 `rift-forge-v06-art-prompts.json`。攻擊特效以現有 Canvas 渲染器繪製，未引入外部素材或特效套件。

## 驗證

- `node --test public/rift-forge/tests/engine.test.cjs`：42 項規則測試，包含新增 Boss 流程、事件支付／回復／取捨、事件存檔、傷害預告與舊版相容。
- `npm run build`：正式建置與所有遊戲資源內容雜湊檢查。
- `npx playwright test --config=playwright.rift.config.cjs`：Chromium／WebKit 的美術、觸控、事件介面、Boss 圖集、舊快取更新與存檔測試。新增截圖使用 QA 配置的明確場景，不冒充自然遊玩進度。
- 六個固定種子（1、2、3、17、99、403）的正常規則模擬均經過三場 Boss、三次事件並結算勝利，戰鬥時間 212–233 秒。策略採用規則式移動、選取強化、進化與充能脈衝，沒有修改傷害或無敵；僅作流程煙霧測試，不代表人類勝率、正式平衡或手機效能。
- 危險區最多 12 個、球 140 顆、敵人 70 隻、特效 210 個、每顆球尾跡 7 點；尾跡不寫入存檔。
