# Rift Forge 0.7 — 元素戰鬥美術

## 玩家看得到的變化

九種攻擊的戰鬥本體與選單圖示分開，改用 `elements.js` 即時繪製。

| 元素 | 飛行形態 | 命中與狀態 |
| --- | --- | --- |
| 火 | 白熱球心、橘紅翻捲焰尾、餘燼 | 向外炸開的火舌；怪物身上持續燃燒 |
| 冰 | 有明暗切面的冰槍、側翼冰晶、冷霧及雪晶 | 冰片炸裂、透明冰殼、藍色覆霜、地面霜裂；依減速剩餘時間消退 |
| 電 | 沿真實飛行軌跡前進的分岔閃電 | 白藍電弧接到實際連鎖目標，接觸點放電 |
| 毒刺 | 帶倒刺的綠色藤蔓與尖刺 | 蔓刺爆散、毒泡上升 |
| 血 | 紅色血彗星、血珠尾流 | 弧形血刃與回到角色身上的生命流 |
| 回音 | 紫色稜晶、錯位殘影、扭曲環 | 交錯空間裂環與分裂碎晶 |
| 蒸裂 | 火球與冰晶包覆 | 冰火雙層衝擊、冰片及蒸氣擴散 |
| 風暴 | 青色閃電與紫色副電弧 | 強化連鎖放電及分裂攻擊 |
| 瘟花 | 荊棘核心與旋轉花瓣 | 六瓣毒花、蔓刺與生命回流 |

施放火花與元素一致；閃避增加三道弧線與殘影。脈衝保留清晰的全場擴散環。
Boss 警示邊框、倒數與「閃避」文字仍繪於玩家特效之上。

## 實作與遊戲規則

- 火焰使用啟動時生成的 12 張 Canvas 快取影格；光暈也採快取。
- 沒有新增圖片下載依賴；既有角色圖集另外快取透明覆霜遮罩。
- 不再以選單圖示充當飛行攻擊；選單保留簡潔、原有色彩的識別圖示。
- 畫面繪製不改動戰鬥、碰撞、隨機數或存檔。冰殼表現既有 45% 減速，不額外施加停住不動的凍結。
- 閃電依真實軌跡折返，連鎖端點來自實際受擊敵人；不增加畫面看似命中卻不存在的傷害判定。
- 精簡模式保留全部九種基本形態、冰殼與危險提示，減少尾跡、霧氣、碎片與細小分岔。
- 系統「減少動態效果」停用火焰翻捲與電弧抖動；必要的投射物位移、命中及狀態消退仍顯示。
- 新腳本同樣使用內容雜湊版本網址，啟動失敗會顯示重試。

## 驗證

既有 43 個引擎案例與瀏覽器回歸測試保留。新增 Chromium / WebKit 的桌面及手機元素畫面、完整及精簡品質、渲染不改動戰鬥狀態、狀態消退、反彈軌跡、減少動態效果、腳本下載失敗復原，以及九種元素真實模擬的影片證據。

大量特效測試包含 70 個帶狀態敵人、140 個有尾跡投射物、90 個命中特效。CI 瀏覽器的耗時不代表實體 iPhone 表現；影片為受控測試場景，以實際引擎推進與碰撞。

## 美術來源

本次全部為原生 Canvas 程式美術，新增來源 `public/rift-forge/src/elements.js`；既有角色、場景圖集沿用 0.6。沒有新增生成圖片或外部素材。
