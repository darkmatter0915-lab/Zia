# Zia Product Notes

## 產品定位

Zia 是給單一使用者的生活與工作控制中心。第一版優先解決「資訊散在不同聊天、備忘錄與腦袋裡」的問題，而不是急著建立複雜的多人協作系統。

## 核心模組

| 模組 | 主要用途 | 資料方式 |
| --- | --- | --- |
| 總覽 | 今日焦點與跨模組狀態 | 自動彙整 |
| 任務 | 待辦、期限、優先順序 | 本機手動 |
| 餐廳 | 日報、檢查、庫存 | 本機手動 |
| 旅遊 | 多旅程、預算、時間軸 | 本機手動 |
| 投資 | 成本、股數與損益 | 手動價格 |
| 車庫 | 里程、保養、保險 | 本機手動 |
| 遊戲 | 進度、狀態與筆記 | 本機手動 |
| 筆記 | 可搜尋的文字資料庫 | 本機手動 |

## 架構

- `data.js` 定義資料模型、預設內容與顯示標籤。
- `store.js` 負責狀態、版本合併、localStorage、跨分頁同步與活動紀錄。
- `app.js` 負責路由、事件、編輯器、搜尋、備份與 PWA 安裝流程。
- `views.js` 負責九個頁面的安全 HTML 輸出。
- `forms.js` 集中管理資料編輯欄位，避免各頁表單規則分裂。
- `utils.js` 提供跳脫、格式化、日期、金額與檔案工具。
- `style.css` 提供桌面、平板、手機、主題與無障礙動態偏好。

## 安全與誠實邊界

- 使用者輸入在輸出至 HTML 前會進行跳脫。
- Content Security Policy 限制資源來源為同站。
- 應用程式不要求 API key，也沒有內建追蹤碼。
- 投資資料明確標示為手動，不宣稱即時。
- 刪除與全部重設需要使用者在執行當下確認。

## 備份策略

Zia 的資料存於瀏覽器。設定頁可以匯出完整 JSON，並在另一個瀏覽器或裝置匯入。這是 1.0 的主要搬家與復原方式。
