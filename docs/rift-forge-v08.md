# Rift Forge 0.8 — 等級成長與裝甲覺醒

角色等級與技能階級現在直接驅動戰鬥美術。所有成長效果都接入原本的射擊、命中、反彈、升級與存檔流程。

| 角色等級 | 外觀 |
| --- | --- |
| Lv.1–4 | 裂隙行者：原本輕裝與赤紅短披風 |
| Lv.5–9 | 重鑄先鋒：層疊肩甲、金邊披風與強化拳砲，使用新的六動作圖集 |
| Lv.10–11 | 覺醒鑄師：金黑重甲、冠盔、青色符文與武器核心，使用第二套新六動作圖集 |
| Lv.12 以上 | 熔爐化身：覺醒重甲加金色能量冠冕、完整符文環與更強武器光效 |

最終形態設於 Lv.12，避免要求一般八波流程難以累積的 Lv.15 經驗量。每次升級都有升級波紋；外觀門檻有更完整的覺醒符文。升級選單顯示目前人物、新形態及下一個造型門檻。角色移動、蓄力、出手、受傷與閃避殘影均使用當前裝甲。

## 技能成長

- 技能 1／2／3 階逐階增加彈體、尾跡和命中特效強度；角色等級另提供每級 1% 的視覺倍率，到 Lv.20 封頂，總倍率最多 1.95，避免高等級覆蓋整個畫面。
- 火球：增加翻捲火舌、餘燼與高階白熱焰環。
- 閃電：從主電弧，增加分岔，再增加沿相同路徑的平行放電。
- 冰晶：從單一冰槍增加至三枚、五枚冰晶，命中碎冰同步強化。
- 荊棘、血核、回音、蒸裂、風暴、瘟花也有逐階大小與細節；進化後的 1 階不會比材料 3 階縮小。
- 閃避殘影、脈衝線條及符文隨角色形態提升。精簡特效仍保留等級差異。

直接傷害仍沿用技能階級 1×／1.6×／2.2× 再乘上基地與被動加成，碰撞半徑、範圍傷害距離、冷卻與隨機數不受渲染影響。高階新細節不擴大實際傷害範圍。頭目地面警示仍在玩家特效上方。

## 相容性與驗證

外觀由既有角色等級推導，舊存檔不需重開；舊飛行彈核補上原角色等級的視覺資料。新增圖集沿用內容雜湊載入、啟動檢查與失敗重試。兩套 WebP 合計約 235 KiB。

引擎測試涵蓋精確門檻、真實 XP 升級、選單期間凍結、技能傷害、碰撞半徑、進化視覺、分裂繼承、舊存檔及 RNG。瀏覽器測試覆蓋 Chromium／WebKit 的橫直向升級選擇、九核三階、完整／精簡特效、舊存檔、新圖集重試及既有手機操作。大量特效場景提升為 Lv.20、140 枚 3 階投射物、70 個帶狀態敵人及 90 個命中特效。瀏覽器模擬不等同實體 iPhone 驗證。

## 美術來源

兩套角色使用內建 image_gen 生成，沿用原角色身分與六動作排列；覺醒圖集另做透明背景編修。只用既有 pack-sprites.py 裁切、縮放、保留 alpha 與轉 WebP。最終檔案：

- public/rift-forge/assets/sprites/hero-veteran.webp
- public/rift-forge/assets/sprites/hero-ascendant.webp

完整原始提示詞、編修提示詞與來源檔名記錄於 [rift-forge-v08-art-prompts.json](rift-forge-v08-art-prompts.json)。技能效果是原生 Canvas 程式美術。
