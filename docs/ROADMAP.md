## 設計原則

1. 本機優先，資料所有權留在使用者手中。
2. 未連接資料源時，清楚標示手動資料，不製造假的即時性。
3. 手機可完整操作，不把重要功能藏在桌面版。
4. 每個模組都能獨立演進，不讓單一功能拖垮整個系統。
