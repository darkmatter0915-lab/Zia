# Zia Workspace 2.0

## 本次介面更新

- 首頁重整為待辦摘要、店務檢查、補貨提醒、旅行計畫、快捷新增、生活工作區與最近活動。
- 首頁的「待處理」同時包含逾期與今天到期的未完成任務，也可切換今天或全部待辦。
- 桌面側欄依日常、生活、工作區分組；手機底部改為總覽、任務、餐廳、旅遊、更多五個入口。
- 九個模組統一字級、留白、按鈕、表單與卡片；新增一致的 SVG 圖示、深淺模式快速切換。
- 手機編輯器採底部展開，輸入欄位使用 16px 字級；窄螢幕新增按鈕保留文字。
- 修正對話框內按鈕的事件委派、搜尋清除未清掉輸入內容、勾選框的原生點擊區。
- 新增未儲存內容離開確認、匯入備份取代資料確認、鍵盤焦點限制與返回、背景操作隔離、儲存失敗提示。

## 資料與範圍

沿用原有 `src/app.js` 的資料操作，以及原有 `store.js`、`data.js`、`forms.js`、`views.js`、`utils.js`。儲存鍵仍是 `zia-control-center-v1`，資料 schema 仍是 1。本次不執行重設或資料遷移。

新增的 WorkspaceApp 是介面層；既有任務、餐廳、旅程、投資、車庫、遊戲及筆記功能仍由原系統處理。資料仍在目前瀏覽器，沒有增加雲端同步或即時行情。

沒有修改地下城遊戲、warrior-asset-lab 原始碼或戰士資產。共用 Service Worker 更新快取版本，僅清理 Zia 自己的 runtime 快取，並避開獨立遊戲與資產路由。

## 驗證

執行 `node --test scripts/test-workspace.mjs`：8 項測試通過，涵蓋待辦篩選、資料不被渲染改寫、使用者文字跳脫、空資料、既有 schema 與快取範圍。

`npm run build` 在本機測試工作區通過。介面原始檔與 main 分支的原始 blob SHA 已比對一致後再修改。

Chromium 的正式 bundle 介面測試：21 項檢查通過，包含九個路由、任務新增/編輯/完成、搜尋結果開啟、清除與關閉、未儲存提示、鍵盤焦點、旅程新增、庫存操作、首頁篩選、深淺主題、JSON 匯出、既有資料初始化、手機選單、底部編輯器與長標題跳脫。畫面寬度檢查涵蓋 320、390、430、768 與 1440px。

測試限制：執行環境禁止瀏覽器網路導覽，因此測試以正式編譯的 JS/CSS 注入空白頁，使用記憶體 localStorage fixture。這不等於真機 Safari、真實跨頁持久化、Service Worker 安裝/更新或離線測試通過；這些項目仍需在實際裝置驗證。

GitHub 的 Verify Workspace UI workflow 會另外執行 8 項 Node 測試與 JavaScript 語法檢查。網站建置與 Pages 發布沿用既有 Deploy Zia to GitHub Pages workflow。

## 更新後使用

沿用原本 Zia 網址，不需建立新帳號或搬移資料。連線狀態下重新載入；若安裝版仍顯示舊版，關閉 Zia 後再開啟。

不要為更新介面而清除網站資料。重要資料請先從設定匯出 JSON 備份。
