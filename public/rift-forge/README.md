# 彈核熔爐 / Rift Forge

0.4 行動體驗更新，2026-09-24。依公開玩法重新設計的獨立單人反彈 Roguelite，不是 BALL x PIT 原始碼或素材的復原。

## 執行與隔離

這個目錄位於 public/rift-forge，由既有 Vite public 複製流程輸出到 dist/rift-forge。不更動 Zia 主介面、舊 ARPG、Warrior Asset Lab 或 Vite 設定。0.3 另加獨立的戰鬥美術驗證 workflow，產生畫面與效能報告，不執行部署。網頁只依賴本目錄的 HTML、JavaScript、CSS 與圖像，沒有外部 CDN。使用靜態 HTTP 伺服器開啟 index.html；部署成功時的相對入口為 /Zia/rift-forge/。分支上的新版本不代表已上線。

規則測試：在這個目錄執行 `npm test`，或從 repo 根目錄執行 `node --test public/rift-forge/tests/engine.test.cjs`。無須安裝套件。package.json 的 CommonJS 邊界只用來讓獨立規則測試可在父專案 ESM 環境執行。

## 已實作

1 名角色、1 個原創 Canvas 戰鬥場景、3 種小怪、1 個雙階段頭目、8 波敵襲。6 種基本球核及 3 組指定進化；四格配装；三選一升級；有限重抽；五種刻印；兩個波次間商店；結算傷害統計；三個有限等級的基地升級。

自動射擊及自動／手動瞄準。A/D 或左右方向鍵移動，Space 閃避，Q 脈衝，E 進化，Esc 暫停。手機左右按鈕移動，觸碰戰場瞄準。回收球可獲得脈衝能量。切換分頁自動暫停。合成音效可關閉。升級卡會標示可合成的搭配；波次進度、接球範圍、牆面反彈與頭目入場有更明確的視覺提示。

只有指定配方進化，沒有任意兩球的通用融合；基地目前是升級面板，不是自由擺放經營地圖。所有數值及圖形均為本專案自訂，不代表原作內部規格。

## 研究重點

BALL x PIT：取反彈戰鬥、局內組合、局外成長的三層循環。Peglin：取瞄準與彈道路線的決策，沒有照搬回合制釘板。Brotato：取自動攻擊、可切手動瞄準與波次間補給。Vampire Survivors：取集中強化的成長感與跨局投資。Ballionaire：取可理解的觸發連鎖，不照搬經濟目標或佈置釘板。

參考遊戲的優點是本專案設計判斷，非人類玩家對照實驗結果。完整研究請參考隨交付原始碼套件附的 RESEARCH.zh-Hant.md。

## 驗證及限制

30 項 Node 規則測試涵蓋反彈、回收、進化、數量上限、存檔、頭目流程，以及新版槍口座標、視覺暫態回收與舊存檔相容。0.4 的瀏覽器驗證從 repo 根目錄執行 `npx playwright test --config=playwright.rift.config.cjs`；透過真正的靜態 HTTP 伺服器測試，使用 localStorage 重載續玩。結果與截圖在 `test-results/`，CI 會保存 14 天。

美術截圖使用明確標示的 QA 預設場景，覆蓋 Chromium 1440×900、926×428、430×932 三種尺寸；頭目與進化特效測試會直接配置狀態，不代表自然遊玩的進度或人類勝率。密集繪製基準包含 70 敵人和 140 球，僅量測 CI 瀏覽器 Canvas 繪製呼叫，不能當作實機 FPS。

0.4 新增 Chromium 與 WebKit 自動測試。WebKit CI 不等於 iOS Safari 真機：iPhone 13 Pro Max、實體多指觸控、長時間發熱、音訊品質、難度平衡及穩定幀率仍需實機驗收。0.1 曾完成 24 個固定策略的正常規則通關模擬；更動發射位置後，不能直接沿用該結果宣稱新版平衡已驗證。

存檔在獨立 rift-forge.v1. 本機前綴，沒有帳號或雲端。清除網站資料會失去進度，寫入失敗有提示。原作影片未完整取得，沒有逐格分析原作或拆解二進位。此為可玩研究版，不是商業完成版。

## v0.3 戰鬥美術

- 五組透明 WebP 圖集：鍊金師、石甲守衛、熔火獵犬、虛空術士、熔鐘守衛，共 30 個姿勢，合計 588,210 bytes（約 574 KiB）。
- 每組六個關鍵姿勢：待機、兩個移動／漂浮姿勢、蓄力、攻擊、受擊。程式依真實攻擊計時切換遠程施法與角色發射，附加死亡淡出和閃避殘影。這是關鍵姿勢動畫，不是完整骨骼動畫或高幀數逐格動畫。
- 九種球核具有各自的輪廓、拖尾與命中特效；冰晶、火焰、電弧、血滴、裂響、毒棘與三種進化效果可用形狀區分。受擊閃白、燃燒／冰緩／中毒、頭目聚能與危險落點提高辨識度。
- 素材載入成功後才能開始；錯誤提供重試。暫停選單可切換精簡特效，降低粒子與像素密度；核心危險提示持續顯示。特效和死亡殘影均有數量上限。

圖集規格在 `assets/sprites/manifest.json`：768×512，3×2 格，每格 256×256，腳底錨點 (128,240)。重新封裝腳本為 `scripts/rift-forge/pack-sprites.py`，需要 Pillow、NumPy、SciPy，輸入五張以角色名命名的原始透明 PNG；只裁切、縮放和封裝，不繪製圖像。

共同生成方向：透明背景、正交斜俯視遊戲角色、厚重清楚的外輪廓、手繪暗色奇幻材質、深青與古銅主色、所有六個姿勢服裝比例一致、無文字與標記。角色分別指定深青裝甲與紅圍巾鍊金師、苔石古銅巨拳守衛、白骨面罩熔火四足獸、紫兜帽單眼漂浮術士、有角銅鐘軀體與熔核雙拳的頭目。未使用第三方遊戲角色參考圖。

## v0.4 行動體驗

沿用 0.3 全部五組角色圖集與九種攻擊效果，不新增角色、美術依賴或存檔版本。

- 觸控裝置左下預設顯示水平滑桿，依推動幅度調整移速；可在暫停選單切換方向按鈕並保存偏好。桌面繼續使用鍵盤與方向按鈕。
- 移動與瞄準各自管理指標，第二隻手可同時操作；放開、取消觸控、失去捕捉或開啟選單會清除對應輸入。
- 戰場依 HUD、控制列與安全區重新配置，保留角色比例；小尺寸橫向縮小裝備文字，直向將移動與技能放在同一列。仍以橫向遊玩為主要設計。
- 橫直轉向或失去焦點自動暫停；繼續時不沿用按住的操作。
- 暫停／選單期間停止重複繪製 Canvas，並暫停 AudioContext；恢復後才繼續。這項改善不等於密集戰鬥已達固定 FPS。
- `tests/mobile.spec.cjs` 測試拖動、雙指標分流、取消、轉向、偏好存檔、音訊狀態、閒置繪製與四種觸控版面。雙指標案例使用明確的合成 PointerEvent，不等於實體多指裝置驗證。

### 0.4.1 回訪玩家美術更新修正

根目錄 Service Worker 原本對 Rift Forge 的未版本化 JS/CSS 採用 cache-first，導致新版 HTML 搭配舊幾何渲染器。現在遊戲資源使用內容雜湊 URL，遊戲入口會更新既有根 Worker；新 Worker 排除本遊戲並只移除 Zia 快取中的遊戲項目。此流程不清除 localStorage、存檔或控制偏好。

修改遊戲程式、美術或樣式後執行 `node scripts/rift-forge/stamp-release.mjs`；正式建置會檢查雜湊是否同步，避免忘記更新。`update.spec.cjs` 在 Chromium/WebKit 中安裝舊 Worker、確認舊 renderer 被快取攔截，然後從原入口開啟新版，驗證五組圖集、存檔續玩與非遊戲快取保留。部署工作也執行遊戲驗證，並比對正式入口、程式及五組圖集的完整內容。
